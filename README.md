# 拼豆小帮手

一款将图片转换为拼豆艺术的工具，支持多平台运行。

## 功能特性

- **图片上传**：支持上传任意图片进行转换
- **像素化处理**：将图片转换为拼豆像素风格
- **颜色映射**：自动匹配拼豆颜色
- **网格预览**：清晰的像素网格展示
- **多平台支持**：H5、微信小程序、支付宝小程序等

## 技术栈

- UniApp
- Vue 3
- Vite
- SCSS

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

#### H5 开发

```bash
npm run dev:h5
```

#### 微信小程序开发

```bash
npm run dev:mp-weixin
```

#### 支付宝小程序开发

```bash
npm run dev:mp-alipay
```

### 生产构建

#### H5 构建

```bash
npm run build:h5
```

#### 微信小程序构建

```bash
npm run build:mp-weixin
```

## 页面说明

### 首页（像素图生成器）

主要功能页面，提供图片上传和像素化转换功能。用户可以选择本地图片，系统会自动将图片转换为拼豆风格的像素图。

### 预览页

展示转换后的像素图效果，支持放大查看细节，方便用户确认拼豆图案。

### 关于页

展示应用介绍和使用说明。

## 使用流程

1. 打开应用进入首页
2. 点击上传按钮选择图片
3. 等待图片处理完成
4. 在预览页查看像素化效果
5. 根据需要调整参数重新生成
